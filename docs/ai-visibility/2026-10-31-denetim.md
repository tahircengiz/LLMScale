## 2. İçerik denetimi — sayfa başına

Ölçütler: (1) başlık hedef soruya denk ve soru biçiminde mi · (2) başlığın altındaki ilk cümle doğrudan cevap mı ·
(3) somut sayı + birincil kaynak linki · (4) tazelik · (5) ad ve tanım tutarlılığı.

**Ortak bulgu, en önemli:** 10 sayfanın ham HTML'inde dışarıya giden link yalnız GitHub reposu ve LinkedIn. Sayfalar
"ZeRO ve QLoRA makalelerine karşı doğrulandı", "her rakam üreticiden" gibi doğrulanabilir iddialar taşıyor, ama
kaynağı linklemiyor. README'nin "The numbers are checked, not asserted" bölümü bu kanıtı veriyor; sitede yok. GEO
deneyinde (Aggarwal vd., KDD 2024, arXiv 2311.09735, Tablo 1) en çok kazandıran yöntemler alıntı, istatistik ve kaynak
gösterme; sitede istatistik zaten güçlü, eksik olan kaynak.

**Ortak güçlü yan:** SSS cevaplarının ilk cümlesi doğrudan cevap ve sayılı (ör. "About 16 bytes per parameter before
activations"); TR sayfalar EN'nin tam karşılığı, terimler (KV cache, context) tutarlı.

### index.html / tr/

1. Başlık: H2'ler arayüz etiketi ("Choose a model", "Precision & workload"), dokunulmamalı. Açıklama başlığı
   `about.sizing.title` "What this calculator assumes" soru değil (isteğe bağlı öneri: "How does LLMScale size GPU
   memory?" / "LLMScale GPU belleğini nasıl hesaplıyor?").
2. İlk cümle: H1'in altı soruyla açılıyor (`header.subtitle`: "How much GPU memory does a model really need? …").
   Cevapla açılması önerilir; llms.txt'nin ilk cümlesi hazır tanım:
   ```diff
   - "How much GPU memory does a model really need? Weights and KV cache scale with your …"
   + "LLMScale works out how much GPU memory a large language model needs — weights, KV cache, context window and concurrent users — from each model's own architecture, and which GPUs hold it. …"
   ```
   (Cümlenin devamı ve TR karşılığı aynı mantıkla; TR anahtarı `dict.ts:1329`.)
3. Sayı var (70B için 131/68/38 GiB; KV cache 131.072 byte/token), birincil kaynak yok. MLA cevabı (`about.sizing.a4`)
   DeepSeek-V2 makalesine dayanıyor (README: §2.1.3) → link: arXiv 2405.04434 (başlık arxiv.org'da doğrulandı).
4. Tazelik: `about.sizing.a4` yalnız "DeepSeek-V2 and V3" diyor; motor DeepSeek-V3.2'nin sparse attention'ını
   (`scripts/test-dsa.ts`) ve DeepSeek-V4'ün compressed attention'ını (`scripts/test-v4.ts`) da test ediyor. Öneri, sayı
   eklemeden:
   ```diff
     "about.sizing.a4": "DeepSeek-V2 and V3 use multi-head latent attention (MLA), … where the usual formula would give 13.34 GiB.",
   + (sona) " DeepSeek-V3.2's sparse attention and DeepSeek-V4's compressed attention are sized from their own config.json the same way."
   ```
5. Tanım: aynı ürün beş ayrı cümleyle anlatılıyor (title, index'in elle yazılmış JSON-LD `description`'ı, llms.txt,
   `package.json`, GitHub açıklaması). Anlam tutarlı; tek kanonik cümle (llms.txt'deki) JSON-LD, README girişi ve GitHub
   açıklamasında kullanılırsa model aynı tanımı her yerde görür. Düşük öncelik.
