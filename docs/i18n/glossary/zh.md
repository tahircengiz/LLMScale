## Yazım kuralları

Yalnız kaynaklarda görülen ve sayılan kurallar. Sayımlar düz metin üzerinden; "boşluklu / bitişik" biçiminde.

- **Çince ile Latin harf ya da rakam arasında boşluk.** Bütün kümelerde baskın: K1 4374 / 101, K2 8664 / 14, K3 840 / 26, K4 1325 / 12, K5 2877 (+585 NBSP) / 234, K6 2293 / 2. Örnek: "KV 缓存", "GPU 显存", "首 token 延迟".
- **Tam genişlikli noktalama.** Çince cümlede virgül, nokta ve iki nokta tam genişlikli: ，。：. İki nokta (： / :): K1 943 / 7, K2 640 / 0, K4 612 / 0.
- **Parantez: iki uygulama var.** Bitişik tam genişlikli （）: K1 133 / 6, K3 22 / 0, K6h PDF (örnek "仓库（也称为 repo）"). Boşluk + yarım genişlikli (): K4 94 / 15, K5 142 / 67, K6 66 / 0 (örnek "多实例 GPU (MIG)"). K2 karışık: 219 / 176. Kısaltma Çince terimin ardından parantezde gelir.

- **GB ve diğer birimler: tutarsız.** Boşluklu "16 GB" yalnız K3'te (60 / 0). Bitişik "2GB": K2 (0 / 15) ve K6h PDF ("80GB", "3TB/s"). Karışık: K1 6 / 7, K5 10 / 12, K6 30 / 22 (DGX Spark sayfasında hem "128 GB" hem "128GB").
- **Büyük sayılar.** Rakam ile 亿/万 arasında boşluk: "70 亿个参数" (K4 25, K5 31, K6 8). Binlik ayırıcı virgül: "5,000".
