如何解读模型名称

开放权重模型的名称把几个相互独立的决定压缩进一个字符串：系列和版本、规模、架构、调优用途，以及量化或打包方式。解读器取斜杠之前的部分作为组织名，把其余部分按连字符和下划线拆开，再依次用这些类别的规则匹配每一部分。

它能识别参数量（8B、350M）、混合专家规模 (8x7B) 和活跃参数 (A3B)；量化方式和格式（AWQ、GPTQ、GGUF 及其 Q 等级、FP8、NVFP4 和 MXFP4、BF16、W4A16、INT4、bitsandbytes 4-bit）；调优类型（Instruct、Chat、Base、Coder、Math、VL、Embedding、Reranker，以及 R1、QwQ、Thinking 等推理类名称）；训练方法（DPO、ORPO、GRPO、LoRA）；上下文长度 (32k)、日期和版本。它只读取名称 — 不同系列的命名惯例各不相同，名称也可能与模型的实际内容不符。

常见问题

模型名称中的 A3B 是什么意思？
在混合专家模型中，表示每个 token 约有 30 亿个活跃参数。Qwen3-30B-A3B 共有 300 亿个参数，但每个 token 只经过合计约 30 亿参数的专家：显存要容纳全部 30B，而每个 token 的计算量更接近 3B 模型。
GGUF、AWQ 和 GPTQ 有什么区别？
GGUF 是 llama.cpp 及基于它的工具所用的文件格式，通常带有 Q4 或 Q8 等量化等级，面向 CPU、Apple Silicon 和消费级 GPU。AWQ 和 GPTQ 是 4-bit 权重量化方法，以 safetensors 格式存储，面向 vLLM 等 GPU 推理引擎。
FP8、NVFP4 和 MXFP4 是什么意思？
比 BF16 更小的浮点权重格式。FP8 每个权重占一个字节，是 BF16 的一半；NVFP4 和 MXFP4 是 4-bit 格式，每个权重半个字节，用于较新的 NVIDIA 硬件以及 gpt-oss 等模型。
Instruct 和 Base 有什么区别？
基础模型只经过预训练，用于续写文本。Instruct 模型（也称 Chat 或 -it）在此基础上进一步调优，能遵循指令并进行对话，这正是大多数应用所需要的。
