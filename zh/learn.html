// 一个语言模型，化作星座

A MACHINE
READS YOUR WORDS

一句话变成由节点组成的星座。拖动、触碰、激发，然后滚动深入其中。

⊹ 拖动 · 悬停 · 点击 · 滚动
01 · 提示

一切从一个句子开始

你把一段文本交给模型：“The cat sat on the mat.”它不会逐个读字母，而是准备把文本看成一个个有意义的片段。

02 · 分词

文本被切分成 token

句子被切成若干片段，每个片段映射为一个数字（ID）。从这里开始，模型处理的是数字，而不是词。

03 · 嵌入

每个 token 变成一个向量

每个 ID 都变成高维语义空间中的一个点。意思相近的，位置也相近。

04 · 注意力

各个 token 相互关注

每个 token 计算自己应对其他 token 投入多少注意力。在因果掩码下，一个 token 只能看到它之前的 token。

05 · 层

同样的模块，层层堆叠

注意力 + 前馈层不断重复，堆叠数十层（例如 ×32）。每经过一层，表示就被进一步细化。

06 · 预测

下一个最可能的 token

最后一层为整个词汇表打分，得到一个概率分布。概率最高的 token 被选中（或通过采样选出）。

07 · 自回归

预测结果被送回输入

选中的 token 被追加到末尾，整个过程再次运行。文本就是这样一个词一个词生成的。

08 · 规模

放大到数十亿规模

这个小小的网络，实际上有数十亿个参数——这正是显存如此重要的原因。你的模型放得进 GPU 吗？
