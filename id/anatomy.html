Anatomi model — ke mana parameter dan memori sebuah LLM digunakan

Memuat anatomi model…

Apa yang ditunjukkan anatomi

Tampilan anatomi membagi parameter model menurut tempatnya berada. Embedding adalah tabel kosakata — dihitung dua kali jika embedding input dan output tidak terikat (tied). Perhatian adalah proyeksi kueri, kunci, nilai, dan output. Selebihnya, sebagian besar jaringan feed-forward atau ahli, dihitung sebagai sisa, sehingga jumlah bagian-bagiannya selalu sama dengan total model yang sebenarnya.

  • embedding = kosakata × hidden size (× 2 jika tidak terikat)
  • perhatian = 2 × lapisan × hidden size × head_dim × (head self-attention + head kunci-nilai)
  • feed-forward / ahli = total parameter − embedding − perhatian
  • ahli aktif (MoE) = feed-forward × ahli per token ÷ jumlah ahli

Grafik cache KV memetakan satu urutan pada FP16 dari nol hingga konteks maksimum model, sampai 128k token. Untuk model dengan grouped-query attention, garis putus-putus menunjukkan biaya multi-head attention penuh — selisihnya adalah penghematan dari GQA. Kartu presisi menunjukkan ukuran bobot pada BF16, FP8 atau INT8, dan INT4.

Pertanyaan

Apa itu grouped-query attention (GQA)?
Beberapa head kueri berbagi satu set head kunci dan nilai. Cache KV bertambah sesuai jumlah head kunci-nilai, bukan head kueri, sehingga model dengan 64 head kueri dan 8 head kunci-nilai menyimpan cache 8 kali lebih kecil daripada multi-head attention penuh.
Mengapa embedding mengambil porsi sebesar itu pada model kecil?
Tabel embedding berukuran kosakata × hidden size, dan kosakata modern berukuran besar. Pada Qwen2.5 7B, embedding memuat sekitar 1,09 miliar parameter dibandingkan 0,82 miliar pada perhatian; lapisan feed-forward mengambil sebagian besar sisanya.
Mengapa model MoE menunjukkan parameter aktif yang jauh lebih sedikit?
Hanya beberapa ahli yang berjalan untuk setiap token. Angka aktif menghitung embedding, perhatian, dan porsi parameter ahli yang benar-benar dilalui sebuah token — memori tetap harus menampung semuanya.
Dari mana datanya berasal?
Dari config.json model dan API model Hugging Face, diambil secara langsung di browser Anda. Unduhan, suka, lisensi, dan ukuran repositori berasal dari sumber yang sama.
